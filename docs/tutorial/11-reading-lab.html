A 最大 Cache tokens = 3+3−1=5，需要 2 blocks。B 最大 Cache tokens = 2+2−1=3，需要 1 block。

Engine 按 batch.items 原顺序拼接 GPU tokens，单次 D2H 得到 [100,200]，构造：

9. 如果 step 1 第 17 层 CUDA 失败

Adapterabort A/B pending；已写层字节不可见，token_count 回到 3/2。
Engine本 step 没有新 Prefill reservation，无需释放新请求。
Schedulerabort outstanding；A/B generated 仍是 [100]/[200]，step index 不前进。
下次 step仍用 token 100/200 重试相同 Decode。

10. 建议实际跟读顺序

  1. 在 engine.py 从 step() 进入 _execute_batch()。
  2. Prefill 分支跳到 qwen_model_runner.py 的 prefill()。
  3. Decode 分支先看 paged_batch.py，再看 decode_batch()。
  4. 在 _attention() 追到 paged_attention_cuda.py。
  5. 最后进入 paged_attention_cuda.cu。
  6. 回到 Engine 看 D2H、apply 与 release。
毕业检查：请解释“写入当前 K/V 后，position=3 但 sequence_length=4”
RoPE position 表示当前 token 在序列中的零基绝对位置，等于追加前历史长度 3。Attention sequence_length 表示当前 Query 可以读取多少个 K/V，写入当前 token 后包含历史 3 个加自己 1 个，所以是 4。
